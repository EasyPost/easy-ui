# Textarea

The `<Textarea />` component allows users to input text on multiple lines.

## Standard

Simple `<Textarea />` with `label`, `placeholder`, and `helperText`.

<Canvas of={TextareaStories.Standard} />

## Custom row height

To specify the visible height of a text area in lines, use the `rows` property.

<Canvas of={TextareaStories.CustomRowHeight} />

## Icon at start

Use `iconAtStart` to place an icon at the top left of the `<Textarea />`. It stays on the first line as the field grows. `iconAtEnd` isn't supported.

<Canvas of={TextareaStories.IconAtStart} />

## Auto-grow

Set `autoGrow` to grow the `<Textarea />` with its content, starting from `rows`. Manual resizing is turned off while auto-growing.

<Canvas of={TextareaStories.AutoGrow} />

To cap the growth, add `maxRows`. The `<Textarea />` grows up to `maxRows` lines, then scrolls. `maxRows` has no effect without `autoGrow`.

<Canvas of={TextareaStories.AutoGrowWithMaxRows} />

Together, `iconAtStart`, `autoGrow`, and `maxRows` make a chat composer.

<Canvas of={TextareaStories.ChatComposer} />

## Large Textarea

Set `size="lg"` for a large `<Textarea />`.

<Canvas of={TextareaStories.LargeTextarea} />

## Label with emphasis

Use `isLabelEmphasized=true` to display a label with emphasis.

<Canvas of={TextareaStories.LabelWithEmphasis} />

## Error

When `validationState` is set to `invalid`, the `<Textarea />` displays with error styles.

<Canvas of={TextareaStories.Error} />

## Visually hidden label

A `label` can be visually hidden by omitted the `label` property, but to main accessibility, provide an `aria-label`.

<Canvas of={TextareaStories.VisuallyHiddenLabel} />
