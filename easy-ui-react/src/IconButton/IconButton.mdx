## Ghost

Use `variant="ghost"` for quiet actions, such as a back arrow beside a page title, an edit icon beside a value, or a row's actions. It's transparent and borderless at rest, and shows a light fill on hover. While a menu or popover it triggers is open, it holds a solid fill. Ghost supports `primary`, `secondary`, and `support` colors.

<Canvas of={IconButtonStories.Ghost} />

<Controls of={IconButtonStories.Ghost} include={["color"]} />

### Ghost sizes

Ghost comes in `md`, `sm`, and `xs`. `md` and `sm` match `<Button />`'s heights, 48px and 32px. `xs` is a 24px icon with no padding, the height of a line of `body1` text, for actions inline with text or in a table row. `<KebabButton />` and `<DataGrid />`'s row actions are ghost `xs`. `xs` is only supported with the ghost variant.
