## Ghost

Use `variant="ghost"` for quiet actions, such as a back arrow beside a page title or an edit icon beside a value. It's the outlined variant without the border: the icon takes the same color in every state, with no background. Ghost supports the same colors as outlined: `primary`, `secondary`, `support`, `warning`, and `inverse`.
