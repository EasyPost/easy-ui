# TabNav

A `TabNav` is a set of styled links that lets users navigate between related pages.

`TabNav` accepts a list of `TabNav.Item`s that function as links. Use the `href` prop to denote the URL for the tab. Use `isCurrentPage` to denote what tab is the current page.

Each `TabNav` should have a unique label. To add the label, add the `aria-label` prop to the `<TabNav>` tag. Omit the term 'navigation'-it is redundant since the role is already defined as 'navigation'.

```tsx
<TabNav aria-label="Account">
  <TabNav.Item href="/settings/billing" isCurrentPage>
    Billing
  </TabNav.Item>
  <TabNav.Item href="/settings/members">Members</TabNav.Item>
  <TabNav.Item href="/settings/api-keys">API Keys</TabNav.Item>
  <TabNav.Item href="/settings/branded-tracker">Branded Tracker</TabNav.Item>
  <TabNav.Item href="/settings/shipping-settings">
    Shipping Settings
  </TabNav.Item>
</TabNav>
```

## Client-side routing

Pass a `navigate` function to `<Provider />` and `TabNav.Item`s navigate through your app's router instead of doing a full page load:

```tsx
import { Provider as EasyUIProvider } from "@easypost/easy-ui/Provider";
import { useNavigate, useHref } from "react-router";

<EasyUIProvider navigate={useNavigate()} useHref={useHref}>
  <TabNav aria-label="Nav">
    <TabNav.Item href="/billing">Billing</TabNav.Item>
  </TabNav>
</EasyUIProvider>;
```

regular `href`s—the router is what keeps them from loading a new page.

## Custom Link Component

A `TabNav` can render custom link components for use in apps that have client-side navigation components, such as Next's `Link` component. Use this when an item needs a specific link component rather than the router configured on `<Provider />`.

Use the `as` prop to pass in a custom component.

```tsx
<TabNav.Item as={CustomLink} href="/custom-link-url" passHref>
  <a>Custom link</a>
</TabNav.Item>
```
