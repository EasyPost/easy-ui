# ComboBox

The `<ComboBox />` component is a text input with a list of suggestions under it. The user types, the list narrows or is fetched, and the user picks a suggestion or—with `allowsCustomValue`—keeps what they typed.

Reach for `<Select />` to pick from a short, fixed list without typing, and `<MultiSelect />` to pick several values.

## Standard

Simple `<ComboBox />` with `label`, `placeholder`, and `helperText`. Pass `defaultItems` and render each one as a `<ComboBox.Option />`; typing filters them. Selecting an option fills the input with its text and calls `onSelectionChange` with its `id`.

## Fetched suggestions

For suggestions fetched as the user types, control the input with `inputValue` and `onInputChange`, pass the results as `items`, and set `isLoading` while a request is in flight. `items` aren't filtered—they're shown as given—and the list opens when they arrive.

`footer` renders content below the options, such as the "Powered by Google" attribution the Places API requires. It isn't an option: it can't be focused or selected, and it shows only while the list is open. A string is styled as caption text.

<Canvas of={ComboBoxStories.AsyncWithFooter} />

```tsx
import { ComboBox } from "@easypost/easy-ui/ComboBox";

export function Component() {
  const [street, setStreet] = React.useState("");
  const { predictions, isLoading } = usePredictions(street);

  return (
    <ComboBox
      label="Street address"
      allowsCustomValue
      inputValue={street}
      onInputChange={setStreet}
      items={predictions}
      isLoading={isLoading}
      onSelectionChange={(key) => key && selectPrediction(key)}
      footer="Powered by Google"
    >
      {(item) => (
        <ComboBox.Option
          id={item.place_id}
          textValue={item.structured_formatting.main_text}
          description={item.structured_formatting.secondary_text}
        >
          {item.structured_formatting.main_text}
        </ComboBox.Option>
      )}
    </ComboBox>
  );
}
```

Selecting an option calls `onInputChange` with the option's `textValue`, so a field that fetches on input change refetches after a selection. The list stays closed for those results, since the user hasn't typed since.
